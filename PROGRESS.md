## 🛠 Как вести таблицы (инструкция для следующего открытия)

**Когда я говорю «прочитай дневник» — читай ОБА файла:**
1. `LEARNING_LOG.md` — конспект теории, шпаргалки, разборы шагов
2. `PROGRESS.md` (этот файл) — дашборд: прогресс, баллы, время

### Где что править в `PROGRESS.md`

| Событие | Что менять | Где именно |
|---|---|---|
| Закончили шаг (например, шаг 3) | Сдвинуть `▲` на новый шаг, добавить `✓` старому, обновить процент | Блок «Общий прогресс по проекту» |
| Закончили шаг | Обновить «Текущий шаг» | Под полоской |
| Провели мини-экзамен | Обновить баллы и комментарии в таблице тем | Блок «Готовность к собеседованию» |
| Тема стала 🔴 → 🟢 | Убрать `!`/`!!!` из колонки приоритета | Та же таблица |
| Новая критическая тема | Добавить строку, поставить `!!!` | Та же таблица |
| «Начинаю обучение» | Записать время старта (например, 14:00) | Жду от тебя, не править сам |
| «Пауза» | Не двигать строку, ждать «продолжаю» | — |
| «Заканчиваю на сегодня» | Добавить строку в таблицу времени, посчитать часы, обновить «Итого» | Блок «Затраченное время» |
| Начали новый день | Добавить новую строку в таблицу времени с новой датой | Та же таблица |
| Следующие действия | Обновить после завершения текущего пункта | Блок внизу |

### Как я (ассистент) обновляю

1. **Перед каждым мини-экзаменом** — копирую таблицу из `PROGRESS.md` и дополняю новой строкой
2. **После теста** — обновляю балл и комментарий, ставлю/убираю `!` по результату
3. **После шага** — сдвигаю `▲`, добавляю `✓`, обновляю процент-полоску
4. **При окончании обучения** — добавляю строку в таблицу времени
5. **Если ты скажешь «прочитай дневник»** — сначала открываю `PROGRESS.md` для контекста, потом `LEARNING_LOG.md` для деталей

### Полоска прогресса — как считать

- Каждый завершённый шаг = `+8.33%` (100 / 12 шагов)
- Сейчас завершены шаги 0, 1, 2 → 3 × 8.33% ≈ **25%**, но в полоске 17%, потому что шаг 0 служебный (инициализация, не обучение); считаем 2 полных учебных шага
- Формула для копипаста: `(кол-во_завершённых_учебных_шагов / 12) × 100`, округлять до целого
- Визуально: `█` — заполнено, `░` — пусто, всего 50 символов между `|`
