## 🎯 Профиль обучения

### Что заходит
- **Длинные разборы с аналогиями** (грузчик/склад, повар/продукты, плагин/коробка)
- **Мини-экзамены по 1 вопросу за раз, БЕЗ вариантов ответа** (ученик сам формулирует)
- **Схемы ASCII-арт** для объяснения потоков и жизненных циклов
- **Объяснение «на пальцах» перед кодом** — сначала «зачем», потом «как»
- **Связь с реальным кодом** — ученик любит видеть в логах, как теория работает
- **Видеть, как ошибка → новая тема** — не чинить ошибку за него, а превращать её в обучающий момент

### Что НЕ заходит
- ❌ Готовый код классов целиком — давай только подсказки и направление
- ❌ Варианты ответа A/B/C/D — это тест, а не понимание
- ❌ Утечка ответов в «Идее на пальцах» (записано в правилах 28.08.2026)
- ❌ Угадывание времени — всегда `Get-Date`

### Сильные стороны ученика
- ✅ Понимает аналогии сразу
- ✅ Не зубрит — пытается понять суть
- ✅ Применяет знания к новым задачам (синтез)
- ✅ **Ловит неточности в вопросах ассистента** — видно критическое мышление (примеры: вопрос 11А #3 — «пример не тестирует фичу», вопрос 12 #2 — «@ComponentScan есть только в Spring Boot»)
- ✅ Комментирует педагогические ошибки ассистента (попросил «не делай явных подсказок»)

### Главное правило про время
> **Не угадывай время — всегда `Get-Date`.** Если ученик говорит про таймер («пауза», «продолжаю», «сколько уже»), сначала вызови `Get-Date -Format "dd.MM.yyyy HH:mm:ss"`.
> Активное время = время БЕЗ пауз. Если разрыв > 30 минут — спросить «это пауза или продолжаем?».

## Что изучено (главное)

| Тема | Суть |
|---|---|
| **Бин** | Объект в контексте Spring |
| **Контекст** | Хранилище бинов + контейнер жизненного цикла |
| **`@Configuration`** | Класс с настройками (включая `@Bean`-методы) |
| **`@ComponentScan`** | Указывает, где искать `@Component`-классы (**Spring Core**, не Boot!) |
| **`@Component`** | «Этот класс — бин, создай его сам через конструктор» |
| **`@Bean`** | Метод, который возвращает бин (для чужих классов или сложной логики) |
| **`@Value`** | Подставляет значение из `properties` (с `:` — default) |
| **`BeanPostProcessor`** | Крючок в конвейере создания бинов. **`after` — после `@PostConstruct`**, не до конструктора |
| **`@PostConstruct` / `@PreDestroy`** | JSR-250. Init/destroy. Для prototype `@PreDestroy` **не вызывается** |
| **AOP: `ProxyFactory`** | Spring оборачивает бин в прокси. Интерфейс → JDK Dynamic Proxy. Класс → CGLIB |
| **SpEL / `@Value`** | `${prop}` — placeholder. `#{expr}` — выражение. `#{${prop} == 'x' ? a : b}` **не работает** |
| **`@PropertySource`** | Грузит properties. **Последний в списке = высший приоритет** |
| **`@ConfigurationProperties`** | Группировка конфига в POJO. Дефолты из Java-полей. Relaxed binding. **Живёт в Spring Boot** |
| **События (Spring 4.2+)** | Любой POJO. `@EventListener` **синхронный** |

## Что повторить перед собесом (приоритет)

1. **SpEL внутри `${}`** — `${}` подставляется **до** `#{}`. Тернарник в `${}` не работает.
2. **JDK Proxy vs CGLIB** — Spring выбирает по интерфейсам. Интерфейс есть → JDK, нет → CGLIB.
3. **Приоритет `@PropertySource`** — последний в списке = высший приоритет (перебирает с конца).

## Топ-10 фраз для собеседования (шпаргалка)

> 1. **«Бин — это объект, созданный и хранимый Spring-контекстом»**
> 2. **«Singleton — один бин на контекст, дефолт»**
> 3. **«Prototype — новый бин на каждый `getBean()`. `@PreDestroy` не вызывается, потому что Spring теряет ссылку»**
> 4. **«`@Component` — класс, сканируется автоматически. `@Bean` — метод, регистрируется вручную»**
> 5. **«`BeanPostProcessor.after` — место для AOP-прокси, потому что к этому моменту бин полностью сконструирован и прошёл `@PostConstruct`»**
> 6. **«`@Transactional` — это AOP-прокси с `TransactionInterceptor`»**
> 7. **«Spring выбирает JDK Dynamic Proxy, если у бина есть интерфейс. Иначе — CGLIB»**
> 8. **«`${}` — placeholder из properties. `#{}` — SpEL-выражение»**
> 9. **«`@PropertySource`: Spring перебирает с конца — последний = высший приоритет»**
> 10. **«`@ConfigurationProperties` живёт в Spring Boot, не в голом Core. Даёт relaxed binding и дефолты из Java-полей»**
